# Plan de Investigación: Arquitectura de Audio Web

## Objetivo
Investigar las mejores prácticas para manejar archivos de audio grandes en aplicaciones web, incluyendo tecnologías, bibliotecas, estrategias de optimización y visualización.

## Tareas Principales

### 1. Tecnologías Fundamentales de Web Audio
- [x] 1.1. Web Audio API - arquitectura y capacidades
- [x] 1.2. AudioContext - gestión y optimización
- [x] 1.3. WebCodecs API para audio
- [x] 1.4. Media Source Extensions (MSE)

### 2. Formatos de Audio Web Optimizados
- [x] 2.1. Comparativa de formatos (Opus, Ogg Vorbis, AAC, MP3, FLAC)
- [x] 2.2. Compresión y calidad
- [x] 2.3. Soporte en navegadores
- [x] 2.4. WebM vs otros formatos

### 3. Estrategias de Streaming y Manejo de Archivos Grandes
- [x] 3.1. Streaming adaptativo de audio
- [x] 3.2. Segmentación de archivos de audio
- [x] 3.3. Buffering y prefetching
- [x] 3.4. Lazy loading de audio
- [x] 3.5. Upload progresivo y reanudación

### 4. Visualización de Audio en Tiempo Real
- [x] 4.1. Visualización de formas de onda
